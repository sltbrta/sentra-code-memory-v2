# Generated contract projections

Files beneath `go/`, `ts/`, and `jsonschema/` are generated by pinned remote
Buf plugins. They are tracked for review and drift detection but must never be
edited by hand. Run `../tools/generate.sh` from this directory's parent through
the documented package command to regenerate them.

The checked-in Go messages are exposed to Bazel as
`//packages/contracts/gen/go/ouroboros/contracts/v1:contracts`. This target
compiles the same generated files used by the Go workspace; services must not
maintain a parallel handwritten wire model.
